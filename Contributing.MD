# Contributing

Thanks for wanting to help! A simple way to start:
1. Open an issue describing the small change you want to make.
2. If you want to code, create a branch named `feature/your-short-description`.
3. Make small commits with clear messages.
4. Create a pull request and describe what you changed.

If you're new to Git, I can create issues, branches, or starter PRs for you — tell me which piece you want first.
