## Getting started (for non-coders)
1. If you want to view the code on your computer:
   - Install Git: https://git-scm.com/downloads
   - Clone the repo:
     git clone https://github.com/nerdcoremaine/POS.git
   - Open the folder in a code editor (Visual Studio Code is beginner friendly: https://code.visualstudio.com/)
2. If you prefer not to install anything you can use GitHub’s web editor:
   - Go to https://github.com/nerdcoremaine/POS and click the Code button → Open with GitHub Desktop or Open in GitHub.dev
